## Sobre o projeto

O projeto consiste na implementação de um sistema de livre escolha utilizando os principais conceitos de POO trabalhados durante as aulas.

### Conceitos utilizados

* Classes
* Atributos
* Visibilidade (`private`, `public`, `protected`)
* Métodos
* Métodos construtores
* Encapsulamento
* Herança
* Getters e Setters
* Sobrecarga de métodos
* Reescrita de métodos (`@Override`)

## Tecnologias

* Java
* Programação Orientada a Objetos
* Git
* GitHub


## Objetivo

Demonstrar, por meio de um sistema funcional, a aplicação prática dos conceitos de **Programação Orientada a Objetos** abordados em aula.

Projeto desenvolvido individualmente como parte da avaliação **P1**.
